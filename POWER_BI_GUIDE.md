# Power BI Report Guide

A `.pbix` file is a Power BI Desktop binary file that can only be created and
saved from inside the Power BI Desktop application (Windows) — it cannot be
generated by a script. This guide gives you exact, copy-paste-ready steps to
build the Power BI report yourself in a few minutes, on top of the cleaned
dataset this project already produces.

## 1. Data source

Use the cleaned dataset produced by this project:

```
data/cleaned_sales_data.xlsx
```

(or `data/cleaned_sales_data.csv` — either works)

## 2. Load the data

1. Open **Power BI Desktop**.
2. **Home → Get Data → Excel workbook** (or **Text/CSV** if using the .csv file).
3. Select `cleaned_sales_data.xlsx`, choose the `Cleaned_Sales_Data` sheet, click **Load**.
4. In **Power Query Editor**, confirm column types:
   - `Date` → Date
   - `Sales`, `Profit`, `Profit_Margin`, `Total_Sales` → Decimal Number
   - `Quantity`, `Year` → Whole Number
   - Everything else → Text
5. Click **Close & Apply**.

## 3. Recommended DAX measures

Create these as **New Measures** in the Fields pane (right-click the table → New measure):

```DAX
Total Sales = SUM('Cleaned_Sales_Data'[Sales])

Total Profit = SUM('Cleaned_Sales_Data'[Profit])

Total Quantity = SUM('Cleaned_Sales_Data'[Quantity])

Total Orders = DISTINCTCOUNT('Cleaned_Sales_Data'[Order_ID])

Average Order Value = DIVIDE([Total Sales], [Total Orders], 0)

Average Profit Margin % = AVERAGE('Cleaned_Sales_Data'[Profit_Margin])
```

## 4. Suggested report pages & visuals

**Page 1 — Overview**
- 4x Card visuals: Total Sales, Total Profit, Total Orders, Average Profit Margin %
- Donut chart: Total Sales by Category
- Bar chart: Total Sales by Region

**Page 2 — Product & Category Analysis**
- Bar chart: Top 10 Products by Total Sales (sort descending, keep top N filter = 10)
- Clustered column chart: Total Sales & Total Profit by Category
- Table: Product, Category, Total Sales, Total Profit, Total Quantity

**Page 3 — Regional Analysis**
- Filled map or bar chart: Total Sales by Region
- Matrix visual: Region (rows) x Category (columns), values = Total Sales
- Pie chart: Orders by Customer_Type

**Page 4 — Trends**
- Line chart: Date (Month) on X-axis, Total Sales & Total Profit on Y-axis
- Slicer: Date range slicer, Region slicer, Category slicer (add these to every page via
  **Sync Slicers** so filtering is consistent across pages)

## 5. Add interactivity

- Select each visual → **Format → Edit interactions** to control cross-filtering.
- Add slicers for `Region`, `Category`, `Customer_Type`, and a date-range slicer for `Date`.
- Use **Sync Slicers** (View → Sync Slicers) so filters apply across all report pages.

## 6. Save

**File → Save As → sales_dashboard.pbix** and save it inside this `powerbi/` folder.

---

### Why no .pbix file is included

`.pbix` is a proprietary binary format that only Power BI Desktop (Windows)
can write. Since this project is built and packaged from a script-based
environment, the `.pbix` cannot be generated here — but every input file,
column, and measure you need is ready to go, so building the report from
this guide takes about 10–15 minutes.
